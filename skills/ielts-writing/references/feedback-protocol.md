# Task 2 feedback protocol

This reference governs teaching feedback only. It cannot change a locked score.

## Evidence before diagnosis

- Every reported problem must be supported by one contiguous quotation from the submitted essay.
- Corpus frequency is not evidence that the current learner has that problem.
- Describe only the broadest problem the text proves. Do not invent a specific grammar subtype from a generic impression.

## Priority

- Return exactly two main priorities, ordered by learning impact rather than error count. Do not add a third.
- Prefer a missing response, unclear position, undeveloped central idea, or broken paragraph logic over isolated local language errors.
- A recurring language pattern may become a main priority when it affects several sentences or clarity. One spelling, article, punctuation, or word-choice slip is normally a correction, not the essay's main diagnosis.
- Preserve demonstrated strengths and do not manufacture a weakness to fill a report section.
- Label each priority `TR`, `CC`, `LR`, or `GRA`. The first priority quotation must exactly equal one `limitation_evidence` quotation from that locked criterion. The second must still be a contiguous essay quotation.

## Action

- Connect each priority to one concrete action on the learner's own sentence or paragraph.
- Keep diagnosis and action one-to-one: explain the observed limitation, then ask for the smallest revision that addresses it.
- Classify the action as `clarify`, `develop`, `support`, `reorganize`, `replace`, `repair`, or `proofread_recurring`.
- Add a `success_check` describing an observable result in the revised text, not a vague promise to improve.
- For each priority, create at least one sentence or logic training item whose `original` is exactly the same quotation as that priority's evidence.
- Do not turn a preferred template, linker count, vocabulary count, paragraph count, or named construction into an IELTS requirement.
- Training must return to the learner's original text; model rewrites and reusable expressions remain optional support.

## Provenance

These rules abstract patterns consistent with official descriptors and verified official feedback. Repeated patterns from low-confidence examiner-claimed learner data may strengthen coverage only when they do not conflict with official material. No corpus essay, score, comment, filename, case ID, or recognizable phrase may be embedded as a teaching anchor.
